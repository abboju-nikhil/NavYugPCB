# NavYugPCB

An AI-assisted KiCad engineering prototype exploring ways to turn natural-language hardware requirements into structured circuit-design data.

## Project status

**Prototype — not currently verified as a runnable application.**

The tracked backend has unresolved import and interface mismatches, and its dependency instructions are incomplete. The setup and generation workflow therefore cannot be relied on yet. This repository does not claim production-ready schematic or PCB generation.

## Planned direction

The project explores local language-model assistance, engineering-document retrieval, and deterministic generation of KiCad project files. These are development goals; they should not be read as verified capabilities of the current checkout.

## Before running

The backend imports, dependency list, and generation interface need to be reconciled before reliable setup instructions can be published. No install or run command is provided until that workflow is verified.
